# Restricted survey inputs

The TurkStat 2024 Household Budget Survey household, person and consumption files are not distributed. Obtain access independently from the Turkish Statistical Institute under the applicable research-access conditions. The household-preparation notebook also reads the survey item dictionary. Set `HBS_DATA_DIR` to your authorised local directory containing `hane_cd_2024.csv`, `fert_cd_2024.csv`, `tuketim_cd_2024.csv` and `hbs_madde_tanim.csv`. Keep that directory outside the Git repository. Full microsimulation requires those inputs; the calibrated five-group SAM and aggregate result tables can be used without them.

Official information: https://www.tuik.gov.tr/ and https://veriportali.tuik.gov.tr/en/press/53957 . The original filename and SHA-256 contracts identify the input version used, without redistributing its records.
